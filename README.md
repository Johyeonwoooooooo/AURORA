## Overview

사용자가 자연어로 원하는 물체와 위치를 말하면 LLM Agent가 명령의 의도와 공간 정보를 해석합니다.

예를 들어,

> "거실에 있는 물병 가져다줘"

라고 요청하면 로봇이 거실로 자율 이동한 뒤 주변을 탐색하여 물병을 찾고, 객체와 상호작용하여 물체를 획득한 후 사용자에게 가져옵니다.

AURORA는 자연어 명령 이해부터 이동, 객체 탐색, 상호작용까지의 과정을 하나의 Agent 기반 파이프라인으로 수행하는 것을 목표로 합니다.

## Key Features

* **LLM 기반 자연어 명령 이해**

  * "거실에 있는 물병 가져다줘"
  * "방에 있는 리모컨 찾아서 가져와"
  * 사용자의 명령에서 대상 공간과 객체를 추출

* **자율 이동 및 경로 계획**

  * 공간 정보를 기반으로 목표 위치까지 경로 생성
  * 장애물을 고려하여 지정된 공간으로 자율 이동

* **YOLO 기반 객체 탐색**

  * 목표 공간에서 주변 객체 탐색
  * 사용자가 요청한 객체를 인식하고 위치 확인

* **객체 상호작용 및 Retrieval**

  * 탐지한 객체에 접근
  * 객체를 획득한 뒤 사용자 위치로 복귀
  * 자연어 명령부터 물체 전달까지 일련의 작업 자율 수행

## System Flow

`사용자 자연어 명령`
→ `LLM 의도 및 공간 해석`
→ `목표 위치 설정`
→ `자율 경로 계획 및 이동`
→ `YOLO 객체 탐색`
→ `객체 접근 및 상호작용`
→ `객체 획득`
→ `사용자에게 복귀 및 전달`
